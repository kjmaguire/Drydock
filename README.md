# Drydock

A local-first, Windows-only desktop app where you create a team of AI coding agents, watch them collaborate in a shared Engineering Room, and approve the results.

**Status:** Phase 0 (verification) complete for what a Linux sandbox can check. See [`docs/phase0.md`](docs/phase0.md) for findings, contradictions that need a decision, and the checks that still need a Windows machine. No application code exists yet.
